# Design changes

## add Yale logo, top left

The website feels flat without it and lacks the clear Yale emphasis we're going for here, should help customers engage with their sense of Yale identity and school spirit.

## Switch to white background, Yale colors and type

This table stakes edit creates consistency with the university. Current colors are a little wonky, off-brand for Yale. Switched to white and blues. 

## Add sort, plus grid or list view

The current setup is somewhat cumbersome and some people prefer list views with more products, less detail, so they can scroll easier. Added toggle to allow both.

## White product photo backgrounds

Some photos have black backgrounds - after discussion with AI, left as-is because the issue was the underlying pictures, which I didn't want to mess with, or editing solutions that could potentially break new additions. Accepted this and moved on.

## Add Handsome Dan above the chat

The wiggling chat window is fun, also add a friendly Yale bulldog named Handsome Dan above it that says "Need help? Let's chat!" to drive user engagement.

## Added rotating campus photos

Added publicly available scenic Yale shots that transition at top of page. This will add some pep to the website without distracting from core clothing themes.

## Choose options on click

Added "Choose options" box that shows the product's color and size options and prices. Lets user see availability without having to click into the page.

## Added shopping cart, top right

can't believe I forgot about this - we need a shopping cart! the shopping cart icon is in top right of webpage, allows inventory adjustment, but will not exceed available inventory. Lets user clear cart as well. Intentionally left checkout options off the site since we aren't set up for that.
